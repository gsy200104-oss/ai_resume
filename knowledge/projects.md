## AI 简历知识库助手

- 项目目标：开发面向招聘场景的交互式 AI 简历，使面试官能够通过自然语言问答了解个人教育背景、科研经历、项目经历和技术能力。

- 开发语言：Python。

- Web 框架：Streamlit。

- 大模型：DeepSeek API，通过 OpenAI SDK 兼容接口调用。

- 知识库：使用 Markdown 文件分别存储教育背景、科研经历、项目经历和技术能力，并按 Markdown 二级标题进行文本切块。

- Embedding：使用 Sentence-Transformers 将用户问题和知识片段转换为向量表示。

- 向量检索：基于余弦相似度计算问题向量与知识片段向量的语义相关度，并通过 Top-K 检索召回最相关的知识片段。

- RAG 流程：面试官问题首先进行 Embedding 向量化，通过语义检索获取 Top-K 相关知识片段，再将检索结果作为上下文交给 DeepSeek 生成回答。

- 多轮对话：使用 Streamlit Session State 保存历史聊天记录，实现连续问答。

- 事实约束：通过 System Prompt 要求模型仅依据检索到的个人资料回答，资料不足时明确提示，降低个人经历问答中的信息编造。

- 来源展示：AI 回答下方展示知识文件来源，方便核查回答依据。

- 交互功能：实现推荐问题按钮、聊天输入、历史消息展示和清空对话等基础交互功能。

- 当前进度：已完成本地可运行的 Embedding + 向量检索 RAG 原型；尚未接入独立向量数据库，尚未完成正式线上部署。
